# Personal Website
This is the personal website for `Dan Jackson` currently hosted on `GitHub pages` and built using: `HTML`, `CSS` and `JavaScript`. `Bun` is used as a tool to bundle the JavaScript and CSS files together and minify to reduce the file size and number of requests.

Website URL: [https://danjackson.com](https://danjackson.com).

## Hosting
The website is hosted on `GitHub pages` here: `https://hackdanismo.github.io/dan-jackson-website/`. When commits or deployments are made to the `main` branch, the website will be redeployed and updated on `GitHub pages`. It is therefore recommended to create a branch and a pull request for any changes before merging into the `main` branch in the repo.

`GitHub` pages provides the SSL certificate to allow the website to use `https`.

## Domain
The `domain` of `danjackson.com` was purchased from [https://www.lcn.com/](https://www.lcn.com/) on `Tuesday 18th August, 2026` and has been paid for 12-months. The `DNS` was setup inside of the Control Panel within LCN once logged in using the account.

## Indexing
Indexing on `Google` has taken place and this was submitted to the `Google Search Console` using the `dan.j.jackson.contact@gmail.com` email address.

## Development
When making changes to the code, `CSS` and `JavaScript` updates should be minified. The output files will be in the `dist/` directory.

```shell
$ npm run build
```
